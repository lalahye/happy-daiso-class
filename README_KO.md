# 행복한 다이소반 — Google 로그인 + Drive + 실시간 학습방 + 학급 포인트

## 이번 버전 핵심

- Google 계정 로그인 / 학생·교사 역할 분리
- 개인 포인트, 포인트 내역, 오늘의 미션, 퀴즈 +3P
- Google Drive 링크 기반 작품전시관·PDF 학습방
- 교사 PDF 문제 수 추정 → 문제별 정답 입력 → 학생 실시간 배포 → 자동 채점
- 투표 안건 제안·쿠폰 제안 교사 화면 실시간 확인
- **우리 반 포인트 적립 기능**
  - 학생이 개인 포인트 중 원하는 만큼 `우리 반 포인트`로 적립
  - 첫 목표 기본값 3,000P
  - 교사가 목표 포인트를 언제든 변경 가능
  - 교사가 이번 목표 보상 후보를 2~6개 등록
  - 교사가 `학생 투표 시작`을 누르면 학생 화면에서 후보 투표
  - 투표 종료 시 1위 보상 하나를 확정하여 학생 홈에 표시
  - 보상 제공 후 `보상 완료 · 새 목표 시작`을 누르면 새 회차는 0P부터 시작
  - 이전 적립 내역은 Firestore에 기록으로 유지

## 꼭 해야 할 설정

### 1. Firebase 설정값
기존 프로젝트에서 사용하던 `src/firebase.js`의 `firebaseConfig` 값을 이 프로젝트에도 넣으세요.
Firebase 프로젝트를 새로 만들 필요는 없습니다.

### 2. Firestore 규칙 다시 게시
프로젝트의 `firestore.rules` 파일 전체를 복사해서
Firebase Console → Firestore Database → 규칙에 붙여넣고 `게시`하세요.

이번 버전은 아래 컬렉션이 추가되었습니다.
- `classPointContributions`: 학급 포인트 적립 기록
- `classRewardVotes`: 목표 보상 투표

### 3. 실행
PowerShell에서 이 폴더를 연 뒤:

```bat
npm.cmd install
npm.cmd run dev
```

표시되는 `http://localhost:5173/` 주소를 브라우저에서 엽니다.

## 교사 화면에서 학급 포인트 설정

교사 로그인 → `🏫 학급 포인트`

1. 목표 포인트 확인/수정 (기본 3,000P)
2. 보상 후보 입력 → `후보 추가`
3. 후보가 준비되면 `후보 저장`
4. `학생 투표 시작`
5. 학생들의 투표 수를 실시간 확인
6. `투표 종료 · 1위 보상 확정`
7. 목표를 달성하고 실제 보상을 제공한 뒤 `보상 완료 · 새 목표 시작`

동점이면 자동 확정하지 않고 안내가 뜹니다. 동점이 풀린 후 다시 확정하세요.

## 학생 화면 흐름

홈 화면에 `🏫 우리 반 포인트` 진행률이 나타납니다.

- `💝 우리 반에 적립` → 1P / 5P / 10P / 20P 또는 직접 입력
- 적립 전 확인창 표시
- 적립한 만큼 개인 포인트에서 차감
- 학급 포인트는 실시간 증가
- 개인 포인트 내역에는 `우리 반 포인트 적립 -10P`처럼 기록
- 보상 투표가 진행 중이면 후보 중 하나를 선택하며, 종료 전에는 선택 변경 가능
- 투표 종료 후에는 확정된 보상 하나가 홈과 학급 포인트 화면에 표시

## 참고
현재 버전은 교실 프로토타입용입니다. 학생의 포인트 변경이 클라이언트에서 이루어지는 구조이므로, 외부 공개 서비스로 확장할 경우 Cloud Functions 또는 서버 검증 방식으로 포인트 처리를 옮기는 것을 권장합니다.
